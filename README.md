## Требования

- Браузер **Google Chrome** (или Chromium-based: Edge, Brave, Opera)
- Архив расширения в формате `.zip` или папка с файлом `manifest.json`
- Базовые навыки работы с файлами

---

## Шаг 1 — Скачай расширение

Скачай последнюю версию расширения из **Releases**

```
hcr-extension/
├── manifest.json   ← обязательный файл
├── background.js
├── content.js
├── popup.html
└── icons/
```

> **Важно:** папка должна содержать файл `manifest.json` — без него Chrome не распознает расширение.

---

## Шаг 2 — Включи режим разработчика

1. Открой Chrome и перейди по адресу:

```
chrome://extensions/
```

2. В правом верхнем углу страницы найди переключатель **«Режим разработчика»** и включи его.

После включения появятся три новые кнопки:
- **Загрузить распакованное расширение**
- Упаковать расширение
- Обновить

---

## Шаг 3 — Загрузи расширение

1. Нажми кнопку **«Загрузить распакованное расширение»**
2. В открывшемся проводнике найди и выбери **папку** с расширением (не `.zip`!)
3. Нажми **«Выбрать папку»**

> Выбирай именно **папку**, а не отдельный файл внутри неё.

---

## Шаг 4 — Проверь установку

После загрузки расширение появится в списке на странице `chrome://extensions/`.

Убедись, что:

- Карточка расширения отображается без ошибок
- Переключатель на карточке включён (синий)
- Иконка расширения появилась в панели инструментов браузера

## Частые проблемы

### `Manifest file is missing or unreadable`
**Причина:** выбрана не та папка.  
**Решение:** убедись, что в выбранной папке есть файл `manifest.json`.

---

### `manifest_version` must be 3
**Причина:** устаревшее расширение с Manifest V2.  
**Решение:** используй более старую версию Chrome
---

### Расширение выключается после перезапуска Chrome
**Причина:** Chrome автоматически отключает неверифицированные расширения.  
**Решение:** при каждом старте браузера заходи в `chrome://extensions/` и снова включай расширение.

---

### `Could not load extension`
**Причина:** файлы повреждены или отсутствуют права на папку.  
**Решение:** перемести папку в удобное место (например, `C:\Extensions\`) и повтори загрузку.

---

## Удаление расширения

1. Перейди на `chrome://extensions/`
2. Найди расширение в списке
3. Нажми кнопку **«Удалить»**
4. Подтверди действие

---

- **Не удаляй папку** с расширением — Chrome загружает файлы напрямую из неё. Если удалишь папку, расширение перестанет работать.
- Если расширение обновилось, нажми кнопку **«Обновить»** на странице `chrome://extensions/`.
- Для постоянного использования рассмотри публикацию в [Chrome Web Store](https://chrome.google.com/webstore/devconsole).
